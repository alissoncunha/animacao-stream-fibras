Abrir a animação no StackBlitz

Cria um projeto estático (template html, sem WebContainer) — esse tipo embeda no Excalidraw sem dar erro de browser.

  1. Clique no botão. O StackBlitz abre com a animação rodando.
  2. No StackBlitz, clique em Save / faça login (conta grátis) para gerar um link fixo do projeto.
  3. Copie a URL do projeto e, no Excalidraw, cole-a com ?embed=1&view=preview no final.
